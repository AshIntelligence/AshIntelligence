## How I think about AI products

- Use agency where ambiguity and variability justify it; keep deterministic work deterministic.
- Ground before generation when the answer should be evidence-based.
- Make permissions, state, budgets and rollout explicit rather than implicit.
- Treat consequential actions as product states with review, not merely backend flags.
- Evaluate the whole product system—not only model quality.
- Keep prototypes inspectable enough to trace input → decision → output.
